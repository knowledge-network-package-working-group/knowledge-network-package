## Metadata Schema
`metadata.json` defines all descriptive information associated with a file, including its source, authors, and any other relevant contextual details. 
### System Variables
Any field starting with `@` is for system use only and should not be edited manually **EVER** by any user.
* `@package_version`: Which version of this specification the file is using.
* `@persistent_id`: The file's unique identifier throughout all systems.
